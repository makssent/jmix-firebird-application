# Upstream

This project was created from the official [Jmix application template](https://github.com/jmix-framework/jmix/tree/a1d7b164b98b028d1abf8ebf831867c3e2816a62/jmix-templates/content/project/application) in the [`jmix-framework/jmix`](https://github.com/jmix-framework/jmix) repository.

This project currently targets Jmix 3.0.0.

The Jmix repository and application template are distributed under the [Apache License 2.0](https://github.com/jmix-framework/jmix/blob/a1d7b164b98b028d1abf8ebf831867c3e2816a62/LICENSE.txt).

This project adapts the template to run on Firebird through [`jmix-firebird-addon`](https://github.com/makssent/jmix-firebird-addon). The changes cover project dependencies, datasource and JDBC driver settings, Liquibase changelogs and integration, and Firebird-specific application configuration.
